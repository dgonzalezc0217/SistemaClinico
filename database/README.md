Se necesita SQLite 3.37.0 o superior.
Se debe crear una base vacía llamada clinica.db dentro de datos.
Se debe ejecutar crear_clinica.sql completo.
Se debe activar PRAGMA foreign_keys = ON; en cada conexión.
Se la creación correcta produce 40 tablas.
Los importes se guardan en centavos y las cantidades facturadas en milésimas.
